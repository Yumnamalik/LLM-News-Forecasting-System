# LLM-Integrated News Forecasting System Using Ontology & Knowledge Graph

## 📌 Project Overview

**LLM-Integrated News Forecasting System Using Ontology & Knowledge Graph** is a Final Year Project that aims to explore the use of Large Language Models (LLMs), Ontology, and Knowledge Graphs for intelligent news analysis and forecasting.

The proposed system will process news information, identify important entities, events, and relationships, and represent this information in a structured knowledge graph using a domain-specific ontology. The LLM component will assist in understanding natural-language news content and using the structured knowledge to support the identification of possible future developments.

The project aims to combine the capabilities of LLMs with structured knowledge representation to make news information more organized, connected, and useful for forecasting.

---

## 🎯 Project Objectives

The main objectives of this project are:

* To investigate the use of Large Language Models for news analysis.
* To design an ontology for representing important news concepts and relationships.
* To construct a knowledge graph from relevant news information.
* To integrate structured knowledge with an LLM.
* To investigate methods for identifying patterns and possible future developments from news information.
* To develop and evaluate a prototype news forecasting system.
